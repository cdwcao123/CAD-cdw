# 测试图纸校准规律

用 `银二井上下对照图.dwg` 转换得到的 DXF 与 `导出巷道数据.json` 对照，坐标全部按 DXF 原始单位统计，不解释为米或毫米：

- 真值包含 98 条巷道、646 个点次、496 个唯一坐标。
- 相邻导线点间距中位数 41.19、P90 105.73、P95 129.39 图纸单位；不能把固定 20/40 m 当作通用阈值。
- 每条巷道的 `border_line_points` 为 2–47 个线段，中位数 4；它们可能是一条边线的多个碎片，不能假定数组长度恒为 2，也不能把前两项直接当作两条完整边线。
- 真值点到最近源圆心的距离：P50 0.62，P75 6.02，P90 18.09，P95 24.16 图纸单位。匹配到 2 图纸单位内的圆半径中位数约 0.50。
- 编号/高程文字到对应点的距离中位数 6.82，P90 25.93 图纸单位。字号不能全局取中位数，因为标题和表格会污染统计；点标注通常处于较小字号分位数。当前使用约 P10 文字高度的 8 倍作为默认关联半径。
- 同一文字不能被多个独立圆重复引用；按最近关系唯一归属。无法唯一判断时保留为人工复核，不能复制给多个点。
- 同心圆只按 DXF 块实例关系合并：同一 `block_ref_id`、同一圆心、不同半径；独立圆不合并。
- 真值附近出现的主要承载图层包括 `0`、`114采区`，以及 `巷道`、`采区巷道` 等命名层。主区必须依据命名巷道层判断，但边线追踪不能只取命名层，也不能无条件纳入 `0/114采区` 的所有建筑和符号线。
- 真值中的 141 组几何交叉全部具有不同标高，没有同标高的直接岔口。中心线只在端点吸附形成连接；两条中心线在中间相交时保留为两个独立巷道对象，不能把交点自动改成拓扑节点。
- 巷道对象按自身标高排序绘制。没有可用标高时先绘制；有标高时按较低值到较高值排序，标高较大的巷道对象最后绘制并位于上层。交叉关系及标高差记录在每个巷道网络的 `crossings` 字段。

有原图与对应真值 JSON 时，运行：

```sh
node <技能目录>/scripts/calibrate.mjs <原图.dxf> <真值.json> <新校准.json>
node <技能目录>/scripts/collect.mjs evidence <原图.dxf> <新证据.json> --rules <新校准.json>
```

校准只给出当前图纸的候选阈值，不能代替逐点审查。`label_association_radius_drawing_units` 取真值标签距离 P90 的 1.1 倍；该数值仍使用原图坐标单位。
