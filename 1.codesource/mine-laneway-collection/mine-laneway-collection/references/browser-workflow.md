# 浏览器操作流程

云系统操作通过当前 AgentOS 提供的第一方浏览器/电脑连接器完成，不使用内置 SDK、固定云接口或预先拼好的登录请求。

当用户输入“不显示页面调用”时，选择连接器提供的后台/隐藏标签页或 `visible=false` 模式，尽量不切换前台窗口，也不主动生成网页截图。若当前连接器只能显示页面，明确说明该限制并询问用户是否接受可见模式；不能把可见操作报告为无界面调用。

1. 从用户处确认目标网址、登录身份和要执行的具体操作。打开用户指定的网站；不要猜测域名或复用其他项目的地址。
2. 登录、验证码和多因素验证由用户完成。不要要求用户在对话里发送密码、短信验证码、Cookie 或访问令牌，也不要读取浏览器私有存储来绕过登录。
3. 登录后先读取页面上的目标矿井、图纸、巷道或数据入口，确认当前页面与用户指定对象一致，再执行上传、导入、编辑或保存。
4. 上传或提交前展示本地文件和将要操作的目标。只有收到当前环境要求的操作授权后才提交；对新增操作先检查是否存在同编码对象，避免重复写入。
5. 以页面显示的成功提示、导入结果列表或目标记录详情作为完成证据。仅收到 HTTP 200、看到上传进度或页面未报错，都不能单独证明业务操作成功。
6. 如果页面响应不明确，先重新查询目标列表或刷新确认；不要自动重复提交。记录失败项和跳过项，保留原始 JSON/DXF。

大规模 CAD 截图不得直接进入对话事件流。需要查看网页或图纸时，按 [图像读取安全](image-safety.md) 先生成小预览。当前没有浏览器连接器、目标系统不可达或登录需要用户操作时，明确说明阻塞点，不伪称操作完成。
