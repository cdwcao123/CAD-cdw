# 巷道采集与推送预览

插件导出 SDK／接口字段的 JSON 数组，无法采集的值及临时巷道编码为 null。缺失标高可按既定规则在同一无歧义巷道的实测锚点之间插值；高度未确认时使用用户指定的默认高差 3。左右距离及平均巷宽由边线估算，使用图纸单位。

可选推送操作调用宿主 egress，向配置的云端接口发送 `{data: [...]}`，不执行字段完整性校验。请在宿主配置 `CLOUDCAD_BASE_URL` 和 `CLOUDCAD_TOKEN`，不要将凭证写入插件包或日志。推送是批量新增，结果不明确时应先在云端核对再重试。

目标系统对 null、坐标单位和字段的实际接受情况，以及真实 SDK 导入，均尚未验证。候选结果需人工核验。
