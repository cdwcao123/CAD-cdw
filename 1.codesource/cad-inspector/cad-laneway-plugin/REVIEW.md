## 二、这一版修掉的 7 个"换图就翻车"的点

| # | 风险 | 以前的行为 | 3.1.0 |
| --- | --- | --- | --- |
| 1 | **块参照（INSERT）里的几何** | 完全忽略；有些图纸巷道画在块里 → 直接识别不到 | 解析 BLOCKS 段并展开 INSERT（含嵌套 3 层、缩放、旋转、图层 0 继承） |
| 2 | **SPLINE / ELLIPSE** | 跳过（弯曲巷道会断线） | NURBS（de Boor）采样 + 椭圆参数采样 |
| 3 | **MTEXT 格式码** | 名称里混进 `\fSimSun|b0;` 之类的乱码 | 统一清洗（`\P`、`\S1^2;`、`\f…;`、花括号） |
| 4 | **多坐标区** | 只保留最大一块，其余全丢（多分区矿图会漏一整片） | 默认只取主区（与旧版一致、结果可预期）；勾选“同时识别多个坐标区”则按网格连通分簇保留成规模的簇，**跨度 >50 km 的簇判定为外来底图并丢弃** |
| 5 | **标高离群值** | 把"长度 2168"当成标高 → 顶底板标高飞到 2168 m | 用中位数+MAD 做离群判定，超出的按邻近巷道修正并告警 |
| 6 | **图层名不标准** | 只按"巷道/井巷/中心线…"等词匹配，图层叫 `114采区`、`GSLAYER` 就选不中 | 新增图层体检：按“几何像不像巷道”（双线配对率、长线占比、闭合比例、总长）打分，结果区列出候选层，点一下即换层重跑 |
| 7 | **静默出错** | 错了也照常给 JSON/DWG | 新增质量评分（A/B/C/D）+ 问题清单；D 级暂停自动下载并提示原因 |

## 三、质量分怎么算（可复核，不是拍脑袋）

```
score = 30×命名率 + 20×标高覆盖率 + 20×双线配对率 + 15×几何覆盖 + 10×坐标合理性 + 5×宽度合理
A ≥ 80   B ≥ 65   C ≥ 50   D < 50（暂停自动下载）
```

同时输出 `quality.metrics`（nameRate / elevRate / pairRate / coverage / medianWidth / clusters）与 `quality.issues`，前端直接展示，也可从 JSON 里取。

## 四、关于"参考 GitHub 上的 AI+CAD 项目"

本机当前**访问不了 GitHub**（`git ls-remote` 返回 `CONNECT tunnel failed, response 502`），因此这一版没有引入外部仓库代码，而是基于仓库内已 vendor 的两个成熟实现 + DXF 规范做的：

- `libredwg`（GPL-3.0，已在 `runtime/`）：DWG→DXF 解码，是识别链路的入口；
- `@node-projects/acad-ts`（MIT，已在 `vendor/`）：DWG 读写，负责结果图纸写出；
- DXF 组码规范（INSERT/SPLINE/ELLIPSE/MTEXT 语义）按规范实现，不依赖猜测。

等网络可用时，计划对比的仓库：`gdsmith/dxf-parser`（INSERT 语义与容错解析）、`ezdxf`（DXF 审计与修复）、Text2CAD/CAD-Coder 一类（用 LLM 做"生成→校验→修复"的闭环）。其中"LLM 只做复核、几何由确定性算法保证"的思路，本插件已经采用（`/review` 接口 + 数值校验）。

## 四·五、超大范围能不能画准？（3.3.0 实测）

- DWG 坐标用 IEEE-754 双精度（约 15～16 位有效数字）。矿区坐标约 3.6×10⁷、放大底图约 5×10⁸，都能精确到 0.001 m 以内；即使到 10¹² 也还有 0.1 mm 精度，矿图不会受影响。
- 实测：在 x≈5.09×10⁸ 坐标写一条 10 km 长巷道，acad-ts 回读坐标、范围、实体数完全一致（`tests/large-range.mjs`）。
- 修了三处"大范围会翻车"的隐患：
  1. 圆弧/样条采样点数加了上限（6000），避免超大半径曲线生成海量点爆内存；
  2. 原来的 `长度≤最大长度×1.2` 会把超长大巷当成图框误删，改为只排除极端异常长线（×5），图框交给"贴边+跨整幅"判定，并新增「最大单条巷道长度」参数；
  3. 质量评分里"总长过大"告警阈值从 400 km 提高到 2000 km，避免大型矿井误报。

## 五、仍需人工确认的情况（会在界面提示，不会静默）

1. **多坐标区**：同图含多个矿区/大样图时默认全部成图，注意筛掉不需要的区；
2. **单线巷道**：没有双线的地方按默认宽度输出，宽度需人工确认；
3. **图层选错**：当所选层总长不到候选层的 35% 时会告警，并给出候选图层；
4. **坐标未配准**：提示“需填写坐标缩放/平移”，否则 JSON 不能直接导入。
