# 巷道台账推送试验版

本包基于 5.8.0，未包含云图 CAD SDK。推送走宿主 `egress`，目标是 `POST /XAYL_Designer/CADCollection/GisLaneway/CreateList`，请求体为 `{data: [...]}`；它新增巷道台账，不负责原图显示或版本更新。

在 ElvesPuck 服务端的合并配置 `env` 中配置 `CLOUDCAD_BASE_URL`（仅 HTTP/HTTPS 来源地址，如 `https://example.test:61012`，不含路径）和 `CLOUDCAD_TOKEN`，再重启插件或宿主使出站操作重新声明。它们不是前端输入，也不写入插件包；请勿将真实令牌发到聊天、日志或文档。该插件申请 `egress` 以及可读取配置环境变量的高风险 `config.read`，需要宿主授权。HTTP 连接不会加密令牌或巷道数据。

页面默认检查当前采集结果，也可选择人工核验后的 UTF-8 JSON 数组。推送会检查矿井、唯一正式巷道编码、必需数值、测点顺序及帮线坐标，映射 `MineCode` 为接口字段 `mineCode`，并删除证据等接口未声明字段。当前采集器产生的 `candidate-*` 临时编码以及未知巷宽、标高等不会自动补造，因此原始结果通常需要人工补全后才能通过校验。推送属于批量新增；超时或返回状态不明确时，请先查询云端，勿直接重复推送。

该版本仅以本地模拟服务验证映射、受控操作声明、阻止无效提交和超时提示。历史内网地址当前连接超时，未验证实际云端鉴权、服务端字段规则或写入效果，也未验证在真实客户端安装。接口声明的成功状态和字段约束仍需在目标系统实测。不要直接将候选结果用于生产台账。
