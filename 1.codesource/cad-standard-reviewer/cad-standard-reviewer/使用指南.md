# CAD 图样审查插件使用指南

本版为预览版。模型识别、OCR 和复杂图纸证据都可能存在遗漏，最终结论需要人工核对。

## 使用流程

1. 在“规则库”上传规则文件。插件先使用解析器提取正文，并尝试由模型进一步整理；模型不可用时仍保留解析结果。
2. 点击“查看和编辑正文”核对内容。编辑后保存会新增正文版本，不修改上传原件。
3. 在“标准库”按需上传标准、材料目录、公差表或参考资料。标准库不是审查必需项。
4. 标准库同样支持查看和编辑正文。结构化 JSON/CSV 可参与精确检查，其他文档作为模型审查依据。
5. 在“标准集合”选择规则文件，并按需增加或删除标准库文件，保存集合版本。可展开查看该版本实际包含的文件。
6. 在“图纸审查”选择集合和 DXF/DWG 图纸。审查固定使用所选集合版本中的规则、正文版本和标准库快照。
7. 模型不可用时，规则和标准库仍可由解析器提取，本地可执行规则继续运行；依赖模型语义判断的项目会标记待确认。

规则文件必选，标准库可选。同一标准库可被多个集合引用；后续编辑规则或标准库后，需要创建新的集合版本，旧版本和已有审查记录保持不变。

## 支持格式

支持 JSON、YAML、YML、CSV、TXT、Markdown、XML、HTML、HTM、RTF、PDF、DOCX 和 XLSX。Excel 当前提取工作表文本，复杂公式、合并单元格、图形和批注可能不完整。

PDF 文本提取和 DOCX OOXML 解析使用 Python 3.10 或更高版本。插件优先使用 AgentOS 自带 Python，其次使用用户环境中的 Python；也可通过 `CAD_REVIEW_PYTHON`（PDF）或 `CAD_REVIEW_DOCX_PYTHON`（DOCX）指定。Windows OCR 直接使用系统原生能力，不依赖 Python。OCR 最多处理前 20 页或图片，识别可能有误。

## 集合版本

集合保存规则文件、可选标准库文件、原件校验值、文档识别片段和正文版本。已有集合可通过“更新版本”增加或删除文件；已完成审查不会跟随新版本变化。旧集合缺少来源识别片段时，插件会在原件哈希和规则快照校验通过后自动从匹配的规则快照恢复。

## 日志

“本机日志”记录上传、解析、规则适用性、模型和审查状态。若规则文件明显属于工艺、生产或其他非 CAD 文档，插件会在调用模型前返回 `RULE_FILE_NOT_APPLICABLE`，记录规则文件名和命中的非 CAD 术语，不再将这种情况误报为模型超时。模型响应不完整或结构错误时会记录批次和字段类型，不保存模型响应正文，并在允许时重试当前批次。

插件包不包含 Python 解释器。隐私资料及审查记录请按本单位的数据保存策略备份。
