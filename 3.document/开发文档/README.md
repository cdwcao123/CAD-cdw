# 开发文档

- `designerV4-大屏二三维设计器系统开发文档.md`：大屏二三维设计器（designerV4）的系统设计说明。
- `云图CADSDK试用包（电科用）/`：客户提供的云图 CAD SDK 试用包。里层 `sdk/` 是接口与类型定义，`demo/` 是示例工程；同名 `.zip` 是原始压缩包，保留作校验。
- SDK 路径在多份交接文档中被引用（原文为 `开发文档/云图CADSDK试用包（电科用）/云图CADSDK试用包（电科用）/sdk`），移动本目录时要同步改文档里的引用。
- demo 工程装依赖需指定镜像：`npm install --registry=https://registry.npmmirror.com`（默认 registry 在本机不可用）。
