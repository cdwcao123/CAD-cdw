# 接口与实现说明

## 鉴权

登录接口：

```http
POST /User/Login
Content-Type: application/x-www-form-urlencoded
```

字段：

| 字段 | 说明 |
| --- | --- |
| `username` | 账号 |
| `password` | 32 位小写 MD5 密码 |
| `checkCode` | 当前环境验证码关闭，传空字符串 |
| `verificationCode` | 当前环境验证码关闭，传空字符串 |

登录成功后，后续请求统一携带请求头 `token`。

## 主要接口

| 能力 | 方法与路径 | 关键字段 |
| --- | --- | --- |
| 当前用户 | `GET /User/Current` | 无 |
| 工作区列表 | `GET /XAYL_WebCad/GisWebcadArea/GetList` | 无 |
| 图纸列表 | `GET /XAYL_WebCad/GisWebcadMapMain/GetList` | `queryJson={"MapName":"","AreaID":"..."}` |
| 图纸详情 | `GET /XAYL_WebCad/GisWebcadMapMain/GetForm` | `keyValue` |
| 文件上传 | `POST /XAYL_WebCad/GisWebcadMapHistory/UploadFile` | `AreaCode`、`FileBase64`、`FileType`、`MapType` |
| 新建/更新图纸 | `POST /XAYL_WebCad/GisWebcadMapMain/SaveForm` | `MapName`、`AreaID`、`ThumbnailField`、`versionInfo` |
| 新建版本 | `POST /XAYL_WebCad/GisWebcadMapHistory/SaveForm` | `ParentID`、`DxfFileId`、`MasFileId`、`VersionDesc` |
| 缩略图转换 | `POST /CloudCad/file/export?outformat=2&pwidth=320&pheight=200` | `in_file` |

文件上传的 `MapType`：

- `1`：图纸文件。
- `0`：缩略图。

上传返回的是相对资源路径，例如：

```text
/webcadMapFiles/LBTEST/20261120140722.mcd
```

实际读取时拼接为：

```text
http://192.168.100.54:61012/webcadMapFiles/LBTEST/20261120140722.mcd
```

## SDK 数据链路

打开 MCD / DWG / DXF：

```text
MCCORE.mcFileService.openCloudDrawingToMcdBuffer(url)
  -> McCore.getDatabase().readMcdFile(buffer)
```

打开 MCTF：

```text
McCore.getDatabase().readUrlMctfFile(url)
```

保存当前编辑内容：

```text
McCore.getDatabase().saveAsMcd()
```

生成当前编辑内容的缩略图：

```text
MCCORE.mcFileService.exportDrawingFileToOtherBlob(
  mcdFile,
  MCCORE.CoreExportFileType.JPEG,
  { w: 1280, h: 720 },
)
```

## 新建图纸

```text
upload(type=1)
  -> upload thumbnail(type=0，可选)
  -> GisWebcadMapMain/SaveForm
```

`versionInfo` 示例：

```json
{
  "DxfFileId": "/webcadMapFiles/LBTEST/example.mcd",
  "MasFileId": "/webcadMapFiles/LBTEST/example.mcd",
  "LayerStyle": null,
  "VersionDesc": ""
}
```

## 保存新版本

```text
upload MCD(type=1)
  -> GisWebcadMapHistory/SaveForm
  -> 用返回的版本 ID 更新 GisWebcadMapMain/SaveForm 的 CurMapVersionId
```

这种方式不会覆盖历史版本，适合当前插件首版。

## AgentOS 客户端限制

本次实现没有修改 AgentOS 客户端源码，交付物是可由浏览器/同源 iframe 打开的独立网页插件。若后续要求出现在 AgentOS 原生菜单、随客户端自动安装或调用仅客户端可用的原生能力，需要客户端侧提供正式插件注册/宿主接口；当前工程无法仅靠云图 CAD SDK 修改客户端外壳。
