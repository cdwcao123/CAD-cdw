# 巷道插件项目 · 交接说明

> 用于新会话继续开发。只保留有效结论与现状，不含已废弃方案。

## 一、目标

客户端上传**原始 DWG/DXF** → 插件识别巷道 → 产出：

1. **巷道图纸**（DWG，双帮 + 点位 + 标高，接近人工采集图样式）
2. **一份 JSON**（与 MAS Cloud CAD 的 `导出巷道数据.json` 同构，可导入/推送）

## 三、MAS 系统事实（已核实）

**对象**：采集图里的巷道是 `ACAD_PROXY_ENTITY`，DXF 名 `MM_MWDBLANEWAY`，类名 `MmDbLaneway`（梅安森），图层 0、颜色 4、ByLayer。几何存在对象内部，**外部无法读取**（`EXPLODE` 拆不开）。

**数据模型**：导线点路径 + 每点左右半宽，帮线由系统按半宽生成。
真值统计（98 条）：宽度全 4.0 m、高 3.0 m、半宽 2.0 m、每巷道 2–34 个点（合计 646）、点间距中位 41.3 m、点位类型「导线点 624 / 停头 22」。

**服务**：`http://192.168.100.54:61012`，Swagger 470 个接口：
`/swagger/mas.xayl.WebCad.Controller/swagger.json`

| 用途 | 接口 | 状态 |
| --- | --- | --- |
| 巷道台账写入 | `POST /XAYL_Designer/CADCollection/GisLaneway/CreateList` | ✅ 已验证可写 |
| 图纸级巷道保存 | `POST /XAYL_WebCad/GisWebcadMapMain/Save`（`lanewayDataList`） | ⏳ 客户修缺列（`series_ventilation`）中 |
| 格式转换 | `POST /CloudCad/file/transform?outFormat=1(mcd)/3(dwg)/4(dxf)` | ✅ DWG→MCD 已验证 |
| 上传/版本 | `POST /GisWebcadMapHistory/UploadFile`、`/SaveForm` | ✅ 已验证 |
| 图纸指向新版本 | `POST /XAYL_WebCad/GisWebcadMapMain/SaveForm` | ✅ 已验证 |

鉴权：Header `token: <JWT>`。**不要把 token 写进代码或文档。**

## 四、已交付能力（4.3.0）

- 上传 DWG/DXF → 识别 → 出 DWG + JSON（3–4 万条线划，2–4 秒）
- 出图样式对齐采集图：双帮线（青 ACI 4）、点位圈（黄 ACI 2，r 0.5 m）、标高（2.0 字高），图层 0
- JSON：25 字段与真值一致；纯 ASCII 转义（`\u8f68`），GBK 系统读取不乱码
- 自然语言限定：如「只保留 +896.8 水平、长度大于 50 米、名称含联络巷的巷道，最多 20 条」
- 系统落地·**文件通道**（已跑通）：DWG → MCD → 上传 → 存新版本 → 图纸指向新版本（`test-01` 可见）

## 五、待解决

1. **几何精度**：对拍真值 ≤10 m 命中 18%（中位距离 59 m）。根因是「从双线反推中线」与「在导线点上点路径」不是同一套构造。
2. **数据通道**：`lanewayDataList` 待客户补列后启用，届时可生成真正的 `MmDbLaneway`。
3. **可选 SDK 路线**：客户端用 `McDbTunnel` 构造对象 → 导出 `.mcd` → 走上表的上传/版本接口。

## 六、有用的事实（避免重复摸索）

- 原始图（银二井上下对照图）**不含代理对象**，全部是普通图元；代理对象只在采集图里。
- 图上小圆圈（r≈0.4，共 1536 个）与真值点位 2 m 内吻合 **57%**、5 m 内 69% → **圆圈即测量点**。
- 标高文字在 `Z_标注` 层（1477 条），沿巷道排布，必须**沿线投影**取，就近配对只有 2% 命中。
- `parse.js` 的文字对象字段是 `.text`（不是 `.value`），这是之前标高取不到的根因。
- 出图模式：`points`（默认，普通实体，兼容所有查看器）/ `center` / `double` / `manual`（块版，部分轻量查看器不渲染块内容）。

## 七、环境注意

- npm registry 不可用（SSL/网络策略），插件开发不依赖 npm；SDK demo 需要 `npm install --registry=https://registry.npmmirror.com`。
- 验证 DWG 用 `accoreconsole.exe /i <dwg> /s <scr>`，脚本需 GBK 编码、CRLF 换行。
- 私有 IP 无法用 WebFetch，可用 `curl` 访问内网服务。
