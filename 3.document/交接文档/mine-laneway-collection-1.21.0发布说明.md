# 矿井巷道采集技能 1.21.0

本次针对错误巷道网络和主说明过长的问题做了两类修正。

采集与绘制：

- 严禁异色双边线、单线和辅助线成巷。
- 增加双线几何质量校验：平行覆盖率、宽度稳定性、方向一致性和测点居中程度不满足时拒绝候选。
- `collect.mjs network` 必须传入测点或最终巷道 JSON，并直接使用原图同色双线；不再通过中线偏移生成边线。
- DXF 绘制端再次校验颜色和几何质量，矩形包线、发散线和不稳定宽度不会写入复核图。
- 同色重叠点优先使用相同块实例、颜色和图层关联文字，再按距离稳定分配。

技能说明：

- `SKILL.md` 从约 12 KB 精简到约 5 KB，只保留硬约束、命令、交付和验证条件。
- 区域、图片、网页和详细规则移入按需读取的参考文件，避免主说明淹没关键规则。

验证：

- 合成回归覆盖异色线排除、远距同色配对、三色重叠点、同块文字优先、发散双线拒绝和单线尾段裁剪。
- 真实 `银二井上下对照图` 点模式产物 226 个，绘制 107 条原始同色双线网络，边界校验失败 0 条。
- 大坐标视口、点模式背景、巷道块和文字输出回归通过。

当前结果仍须专业人员对照原图复核。严格几何校验会排除部分灰区候选，采集数量可能低于旧版；错误矩形包线和跨色配对优先不交付。
