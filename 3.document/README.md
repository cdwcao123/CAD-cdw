# 3.document · 文档与数据

项目文档、交付示例、真值数据和外部资料。代码在 `../1.codesource/`，安装包在 `../2.zip/`。

| 目录 | 内容 |
| --- | --- |
| `交接文档/` | 面向接手人的现状说明：目标、代码位置、已验证能力、待解决问题、环境注意 |
| `开发文档/` | 大屏二三维设计器开发文档、云图 CAD SDK 试用包原始 zip（解压版目前在根目录 `文档/` 下） |
| `交付示例/` | 历史示例成果（DWG / JSON / 效果图）与打包、对拍过程产物；过程产物约 50 MB，属测试性质 |
| `真值图纸/` | 客户原始图纸与人工采集真值 JSON，用于对拍复核，不要修改 |
| `国睿测试数据/` | 国睿图样审查的测试图与规则文件（支架组件 DXF/PDF、二维图样审查规则 docx） |
| `云图CAD插件/` | 云图 CAD SDK 接入说明、接口映射、部署与验收录 |
| `参考/` | 外部资料：text-to-cad 使用说明、插件移动端截图 |
| `环境与VPN/` | 访问客户内网用的 VPN 客户端与配置，不属于交付物 |
| `删除清单.md` | 本次整理的删除清单、分类与理由 |

## 说明

- 文档里的路径引用（如 `E:/kuangshan/开发文档/...`、`E:/kuangshan/delivery/...`）是整理前的旧路径，对应内容现在分别位于 `3.document/开发文档/`、`3.document/交付示例/`。
- `交付示例` 与 `真值图纸` 里有客户图纸，外发前按客户要求脱敏。
