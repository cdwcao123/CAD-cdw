# 真值图纸

客户（银星二号煤矿）提供的原始图纸与人工采集真值，用于算法对拍与复核。**不要修改、覆盖或重命名原图。**

- `银星图纸/银星图纸/`：原始 DWG —— 银二井上下对照图、银星2号已采集巷道图、采掘工程平面图（10 煤 / 18 下煤 / 2025.10.13）等，另有 `系统设备点位布置图/`。
- `银星图纸/银星图纸/导出巷道数据.json`：人工采集真值，GBK 编码、顶层数组，98 条巷道、646 个点次、496 个去重坐标；宽度 4.0 m、高 3.0 m、半宽 2.0 m，点位类型为导线点/停头。
- `银星图纸.zip`：上述目录的原始压缩包，保留作校验。

## 提示

- 原目录里的 `.dwl` / `.dwl2` 是 AutoCAD 打开图纸时生成的锁文件，迁移后已清理，不影响图纸数据。
- 读取 `导出巷道数据.json` 要按 GBK 解码，否则中文巷道名会乱码。
- 这批图只用于对拍，外发前需客户确认。
